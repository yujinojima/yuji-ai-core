# Epistem Response Template

Use this structure when answering "why does this matter?" questions.

---

## [Topic]

### Layer 1 — Simple Meaning
[What is this, in plain language? 1-2 sentences max.]

### Layer 2 — Practical Relevance
[Why should I care? How does this affect my work, decisions, or understanding right now?]

### Layer 3 — System Relevance
[How does this connect to larger systems? What second-order effects matter? What patterns does this fit into?]

### Layer 4 — When to Use / When Not to Use
[When is this load-bearing? When is it noise? What are the tradeoffs?]

---

### Classification
- **Type:** [foundational / tactical / strategic / noise]
- **Domains:** [which of the user's domains this connects to]
- **Confidence:** [high / medium / low — how sure are you about this assessment?]

### Further Reading
[Optional. Only if genuinely useful resources exist.]
